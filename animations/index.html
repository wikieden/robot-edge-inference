跑起来看（按钮、滑块能动）

在仓库根目录的 Claude 会话里说"打开端侧推理第 N 章动画"即可（.claude/launch.json 里的 ai-infra-edge-animations 配置）。自己在终端跑：

python3 -m http.server 8365 --directory ai-infra-edge/notes/animations

然后浏览器打开 http://localhost:8365/01-robot-constraints.html。直接双击 html 也能打开。

新增或修改一个动画

  1. 页面引用 anim.css 和 anim.js（从 ai-infra/notes/animations/ 复制来的同一套），提供 reset(seed) 和 next()（返回 false 表示播完），用 setupPlayer({captureSeed, reset, next}, 毫秒) 挂上播放按钮。
  2. 重新录 GIF（在本目录下执行），录完删掉多出来的 *-last.png：

bash node ../../../tools/anim-capture/capture.mjs 01-robot-constraints.html 01-robot-constraints.gif 1500

  1. 在对应讲义里写 ### 动画演示，嵌 GIF、链 html；在仓库根目录跑 python3 tools/gallery/build.py。
